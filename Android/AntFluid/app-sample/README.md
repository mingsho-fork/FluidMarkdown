# app-sample

演示应用（Demo），展示 AntFluid Markdown 各模块的组合使用效果。

## 主要功能

- `SampleMarkdownPlugins`：演示如何组装完整的插件链
- `ListActivity` / `MarkwonListAdapter` / `MarkdownHolder`：列表形式渲染多种 Markdown 样例
- `PrinterActivity`：流式打印（打字机）渲染效果演示
- `MyImageHandler`：自定义图片加载器接入示例

## 运行方式

在 Android Studio 中直接运行 `app-sample` 模块即可。
